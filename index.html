ABOUT

野村 広

秋田県仙北市在住。日本語教師、接客、総務・経理など、 幅広い業務を経験してきました。 現在は、これまでの社会人経験を生かしながら、 Java Webアプリケーションの開発と学習に取り組んでいます。

Javaを軸に、Servlet・JSP・JDBCを用いた Webアプリケーションを開発しています。 過去にPHPで制作した在庫管理アプリの仕様をもとに、 画面遷移、データベース設計、処理の流れを一から考え直し、 Java版として再設計・再実装しました。

コードを動かすことだけを目的とせず、 データがどのように流れるのか、 各クラスがどのような役割を担うのかを理解しながら 実装することを大切にしています。 開発中に発見した不具合についても原因を調べ、 ロジックを組み直しながら改善してきました。

制作したJava Servlet版在庫管理アプリは、 Git・GitHubでバージョン管理を行い、 Herokuへデプロイして公開しています。 今後はPostgreSQLへの移行と Spring Bootによる再構築に取り組み、 Java Webアプリケーションの開発・保守に貢献できる エンジニアを目指しています。

趣味は読書、クラシック音楽、 古いパソコンへのLinux導入です。 メキシコに3年間滞在した経験があり、 スペイン語での日常会話ができます。
